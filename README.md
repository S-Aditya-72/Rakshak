# RAKSHAK · Team Git Happens

ChronoForge 2026, NITK Surathkal (Cybersecurity · Cities of the Future). An AI safety layer that reads a child's chats
as conversations, remembers warning signs across days and chats, and responds in levels: a private nudge to the child,
an alert to the guardian, or a critical alert with guided help.
